# Investigación: Sistemas Multi-Agente (MAS)

## Concepto
Un sistema multi-agente (MAS) es un sistema computacional compuesto por múltiples agentes inteligentes interactuando. Pueden resolver problemas que son difíciles o imposibles para un agente individual o un sistema monolítico.

## Características
- Autonomía: agentes parcialmente independientes y autónomos
- Vistas locales: ningún agente tiene visión global completa
- Descentralización: ningún agente designado como controlador

## Tipos de Agentes
- Pasivos: sin metas (obstáculos, recursos)
- Activos: con metas simples (flocking, presa-depredador)
- Cognitivos: con creencias, deseos, intenciones (BDI)

## Patrones de Coordinación
- Basados en contrato: challenge-response-contract
- Basados en feromonas: información dejada para otros agentes
- Votación vs Consenso: mecanismos de decisión colectiva
- Debate: discusión estructurada entre agentes

## Frameworks LLM-based
- CAMEL: communicative agents para exploración de mente
- AutoGPT: agentes autónomos con descomposición de tareas
- CrewAI: orquestación de equipos de agentes
- MALLM: evaluación sistemática de configuraciones MAS

## Aplicaciones
- Comercio electrónico y subastas
- Respuesta a desastres
- Vehículos autónomos y tráfico
- Simulación de sociedades
- Sistemas de poder y smart grids
