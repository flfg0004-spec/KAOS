# Structurizr

**Tipo**: concepto técnico
**Tags**: #structurizr #c4 #diagramas #dsl

Herramienta de diagrams-as-code para modelado C4. Permite definir arquitectura en DSL y exportar a PlantUML, Mermaid, JSON. Licencia Apache 2.0 — gratuita y local. En KAOS se accede vía [[structurizr-mcp]] (wrapper Python) o directamente via `npx @structurizr/cli`.
