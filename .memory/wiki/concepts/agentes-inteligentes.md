# Agentes Inteligentes

**Tipo**: concepto técnico
**Tags**: #agentes #ia #autonomia #mas

Componentes autónomos de software que perciben su entorno, toman decisiones y ejecutan acciones. Características clave: autonomía, reactividad, proactividad, capacidad social. En KAOS, cada agente ([[aletheia]], [[kosmos]], [[metis]], [[mnemosyne]], [[kratos]]) es un agente inteligente con rol especializado.
