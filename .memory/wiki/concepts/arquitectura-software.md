# Arquitectura de Software

**Tipo**: concepto técnico
**Tags**: #arquitectura #diseno #patrones #c4

Disciplina de diseño estructural de sistemas de software. En KAOS se documenta via: ADRs (decisiones arquitectónicas), diagramas C4 (Structurizr), documentación técnica en schema/. Principios: separación de concerns, acoplamiento débil, alta cohesión, evolucionabilidad.
