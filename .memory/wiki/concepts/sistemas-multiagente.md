# Sistemas Multi-Agente

**Tipo**: concepto técnico
**Tags**: #mas #multiagente #agentes #orquestacion

Sistemas compuestos por múltiples [[agentes-inteligentes]] interactuando. Características: autonomía, vistas locales, descentralización. Patrones: challenge-response-contract, feromonas, votación/consenso, debate. Frameworks LLM: CAMEL, AutoGPT, CrewAI. KAOS implementa un MAS con [[aletheia]], [[kosmos]], [[metis]] y [[mnemosyne]].
