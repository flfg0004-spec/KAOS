# Ecosistema

KAOS es un ecosistema de agentes de IA que integra:

- **Gateway LLM**: Hermes Agent v0.15.2 con proveedores MiMo → OpenRouter → DeepSeek
- **Agentes OpenCode**: 7 agentes con 26 MCP servers
- **Vault de conocimiento**: Wiki con 160+ páginas, 91 entidades, 339 relaciones
- **Pipeline LangGraph**: 14 nodos con fases secuenciales y paralelas
- **Scorer de calidad**: MnemoBEAM (8 dimensiones, score 0.803)

Ver SESSION.md y index.md para estado actual.
