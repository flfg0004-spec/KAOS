# Conceptos

Explicaciones detalladas de conceptos clave del ecosistema KAOS.

## Estructura

Cada nota de concepto debe incluir:
- **Definición**: Qué es y para qué sirve
- **Contexto**: Dónde se usa dentro del sistema
- **Relaciones**: Enlaces a otros conceptos relacionados
- **Ejemplos**: Uso práctico cuando aplique
