# MiMo-V2-TTS — Síntesis de Voz

## Descripción

**MiMo-V2-TTS** es el modelo de síntesis de voz de la familia [[MiMo]]. Genera voz natural y expresiva a partir de texto, diseñado específicamente para el ecosistema de dispositivos Xiaomi.

## Características

- **Voz natural**: Síntesis con emociones y énfasis contextual
- **Multi-idioma**: Soporte para múltiples idiomas (énfasis en chino e inglés)
- **Baja latencia**: Optimizado para inferencia en dispositivo
- **Expresividad**: Control de tono, velocidad y emoción

## Aplicaciones

- **[[hyperos|HyperOS]]**: Asistente de voz para teléfonos, tablets y smart home
- **[[Miclaw]]**: Salida de voz para el agente autónomo
- **[[xiaomi-su7|Xiaomi SU7]]**: Asistente de navegación y comandos de voz en vehículo
- **Smart speakers**: Altavoces inteligentes Xiaomi
