# Orquestación de Agentes

**Tipo**: concepto técnico
**Tags**: #orquestacion #coordinacion #pipeline #mas

Patrones de coordinación entre múltiples agentes. En KAOS: pipeline secuencial (Aletheia→Kosmos→Metis→Mnemosyne), verificación cruzada triangular, contexto compartido via `_pipeline/context.json`. Mecanismos: step-done trigger, auto-curation al completar pipeline.
