# Structurizr MCP

**Tipo**: concepto técnico
**Tags**: #structurizr #mcp #c4 #diagramas

Servidor MCP en Python que envuelve el CLI de Structurizr. Tools: `validate_dsl` (validar sintaxis DSL), `export_diagram` (exportar a PlantUML/Mermaid/JSON), `list_views` (listar vistas). Sin licencia requerida — usa `npx @structurizr/cli` (Apache 2.0). Implementado en `.memory/_scripts/mcp_structurizr.py`.
