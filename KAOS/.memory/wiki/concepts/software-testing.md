# Software Testing

**Tipo**: concepto técnico
**Tags**: #testing #calidad #verificacion #validacion

Verificación de software contra especificaciones. Niveles: unit, integration, system, acceptance. Pirámide de testing: unit → integration → E2E. Categorías: funcional/no-funcional, caja blanca/negra, estático/dinámico. KAOS implementa: smoke (2min), functional (15min), audit (60min), cross-agent verification.
