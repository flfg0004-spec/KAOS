# OKR Framework

**Tipo**: concepto estratégico
**Tags**: #okr #estrategia #objetivos #metricas

Framework de definición de metas: Objectives (cualitativos, inspiradores) + Key Results (3-5 métricas cuantitativas). Popularizado por Grove (Intel), Doerr (Google). Best practices: target 70%, scoring 0-1.0, leading indicators, evitar BAU. [[metis]] usa OKRs para planeación estratégica.
