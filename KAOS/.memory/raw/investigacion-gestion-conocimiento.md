# Investigación: Gestión de Conocimiento (Knowledge Management)

## Concepto
Procesos enfocados en la conciencia organizacional, aprendizaje, colaboración e innovación mediante el uso y compartición de conocimiento.

## Dimensiones del Conocimiento
- **Tácito**: internalizado, difícil de articular (know-how, experiencia)
- **Explícito**: codificado, fácil de comunicar (documentos, bases de datos)
- **Espiral SECI** (Nonaka & Takeuchi): Socialización → Externalización → Combinación → Internalización
- **Embebido**: conocimiento en sistemas y procesos
- **Corporizado**: capacidad aprendida del cuerpo humano

## Estrategias de KM
- **Codificación**: documentar conocimiento explícito (people-to-document)
- **Personalización**: compartir conocimiento tácito directamente (persona-to-persona)
- **Push**: gestionar conocimiento activamente en repositorios
- **Pull**: consultar expertos ad-hoc según necesidad

## Ciclo de Vida del Conocimiento
1. Creación: investigación, innovación, aprendizaje
2. Almacenamiento: bases de datos, wikis, vaults
3. Transferencia: comunidades de práctica, mentoring
4. Aplicación: uso en decisiones y operaciones
5. Protección: patentes, copyright, secretos comerciales

## Tecnologías KM
- Wikis y bases de conocimiento (Obsidian, Notion, Confluence)
- Sistemas de gestión documental
- Portales empresariales
- Comunidades de práctica
- Semantic Web y ontologías
- Knowledge graphs

## Personal Knowledge Management (PKM)
- Gestión de conocimiento a nivel individual (1999)
- Herramientas: Obsidian, Roam, Logseq, Notion
- Prácticas: Zettelkasten, PARA, CODE (Capture-Organize-Distill-Express)
- Beneficios: aprendizaje continuo, conexión de ideas, output consistente
