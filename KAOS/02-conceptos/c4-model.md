# C4 Model

**Tipo**: concepto técnico
**Tags**: #c4 #arquitectura #diagramas #modelado #structurizr

Modelo de visualización arquitectónica creado por Simon Brown. 4 niveles: Context (sistema+actores), Container (apps+databases), Component (módulos), Code (detalle). [[structurizr]] implementa diagrams-as-code para C4. [[kosmos]] lo usa para documentar ADRs y arquitectura de KAOS.

**Relacionado con**: [[adr]], [[arquitectura-software]], [[structurizr-mcp]]
