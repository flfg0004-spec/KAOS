# Prompt Engineering

**Tipo**: concepto técnico
**Tags**: #prompt-engineering #llm #tecnicas #context-engineering

Diseño de entradas para modelos generativos. Técnicas: Chain-of-Thought, Tree-of-Thought, few-shot, role assignment. Context engineering: system prompts, tool definitions, token budgeting. Automatización: DSPy, auto-CoT, gradient descent. Riesgos: prompt injection, sensibilidad a formato.
